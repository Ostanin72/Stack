# Домашнее задание к лекции 7. «Подготовка к собеседованию»

### stack.py
Реализован класс Stack
Методы:
- проверка стека на пустоту,
- добавление нового элемента на вершину стека
- удаление верхнего элемента стека
- возвращение верхнего элемента стека
- возвращение количества элементов в стеке 

### utils.py
Функция проверки сбалансированности скобок.
Принимает строку со скобками.
Возращает "Balanced" или "Unbalanced".

### test_utils.py
unit-test функции проверки сбалансированности скобок.

### main.py
Пользовательский ввод строки скобок для проверки сбалансированности
с проверкой валидности ввода.
Вывод работы программы проверки сбалансированности скобок.
